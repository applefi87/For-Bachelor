# 十小時測試：PTB-XL 心電圖

> 這不是在教你做作品集。這是一個測試，用來回答一個你想不出答案的問題：
> **當這些東西在你眼前跑起來的時候，你會不會想知道它是怎麼運作的。**

---

## 先講清楚這個測試在測什麼

程式我已經寫好了，而且在我這邊實際跑過，確認每個函式呼叫都正確。所以這**不是在測你會不會寫程式**——那個測試沒有意義，因為你可以問 AI。

真正的測試是：**跑起來之後，你會不會想改它。**

- 如果你看到那張 3D 圖，會想「如果換一組特徵會怎樣」——那是興趣
- 如果你看到分類準確率，會想「為什麼是這個數字」——那是興趣
- 如果你跑完覺得「喔，跑完了」然後關掉——那也是答案，而且是很有價值的答案

**兩種結果都不算失敗。** 唯一的失敗是三個月後你還在猶豫。

## 環境建置（Windows 11）

### 1. 裝 Python

到 [python.org](https://www.python.org/downloads/) 下載 **Python 3.11**（不要用 3.13，部分套件還沒跟上）。

安裝時**務必勾選 "Add python.exe to PATH"**。這是最常見的踩雷點。

裝完後開 PowerShell 確認：

```powershell
python --version
```

應該顯示 `Python 3.11.x`。

### 2. 建立工作資料夾與虛擬環境

```powershell
mkdir C:\ecg10h
cd C:\ecg10h
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

如果最後一行報錯說「無法載入指令碼」，先執行這行再重試：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

成功的話，提示字元前面會出現 `(.venv)`。**之後每次開新的 PowerShell 都要先跑一次 Activate。**

### 3. 裝套件

```powershell
pip install wfdb neurokit2 antropy umap-learn plotly scikit-learn pandas matplotlib
```

大約 2–5 分鐘。這些版本我實際測過可以互相搭配：

| 套件 | 用途 |
|---|---|
| `wfdb` | 讀 PhysioNet 的資料格式 |
| `neurokit2` | 生理訊號處理（濾波、R 波偵測、HRV） |
| `antropy` | 熵與複雜度指標 |
| `umap-learn` | 降維 |
| `plotly` | 可旋轉的 3D 互動圖 |
| `scikit-learn` | 分類器 |

### 4. 把這四個 .py 檔放進 `C:\ecg10h`

然後照順序跑。

## 執行順序

```powershell
python 01_check.py
python 02_first_ecg.py
python 03_features.py
python 04_model_3d.py
```

**每一步跑完再跑下一步。** 任何一步出錯就停下來，把完整的錯誤訊息貼給我。

## 我測過什麼、沒測過什麼

誠實說明，免得你踩到我沒警告的坑：

**已在我的環境實際驗證**：所有套件可共存、`ecg_clean` / `ecg_peaks` / `hrv_time` 的呼叫方式、`antropy` 三個熵指標、隨機森林 + 交叉驗證、負對照、UMAP 降到 3 維、Plotly 輸出可旋轉 HTML。整條鏈路跑完 60 筆訊號約 20 秒。

**沒能驗證**：從 PhysioNet 實際下載資料這一步——我這邊的網路被擋住了。`01_check.py` 就是專門用來確認這一步的，五分鐘內會給你綠燈或紅燈。

**已知的坑**：`neurokit2` 的 `ecg_simulate()` 在某些心率參數下會直接卡死（我踩到了）。你的流程不會用到它，但如果你之後自己玩，避開這個函式。

## 該期待什麼數字

免得你看到結果以為壞掉了：

用「單一導程 + HRV + 熵」這組簡單特徵去分 NORM vs MI，**AUC 大概會落在 0.65–0.80 之間**。不會是 0.95，也不該是。

心肌梗塞的特徵主要在 ST 段和 Q 波的形態上，而我們現在只看心律和訊號複雜度——**等於是用間接證據在猜**。分得出一些，但分不乾淨。

這不是失敗，這是誠實的起點。真正有意思的問題正是從這裡開始：**要加什麼才會變好？** 那就是研究在做的事。

如果你的負對照（打亂標籤）AUC 也跑到 0.7 以上，那才是出事了——回來找我。
