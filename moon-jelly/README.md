# 海月水母館 Moon Jelly Aquarium

一座只屬於你的夜光水母缸。把煩惱寫下來餵給水母、和牠們一起呼吸、讓兩隻水母孕育出從沒見過的新水母。

這裡沒有輸贏，水母也不會死掉，餓了只是比較不亮而已。

## 怎麼打開

- **直接開**：用瀏覽器打開 `index.html` 就能玩，不需要安裝任何東西。
- **單一檔案版**：`node tools/build-single.js dist/moon-jelly.html` 會把全部東西合成一個 HTML 檔，可以直接傳給朋友。
- **放上網路**：在 GitHub 的 Settings → Pages 選擇從 `main` 分支部署，就能用 `https://<帳號>.github.io/<repo>/moon-jelly/` 打開。

建議開聲音，戴耳機更好。

## 心情與生態：這個網站的核心

有感覺的時候，按下方的「心情」，走一個很短的儀式：

1. **倒出來**：想寫就寫。預設不保存，結束時它會溶進海裡。只想發洩的話，按「只想倒出來，不整理了」，直接交給水母吃掉。
2. **取名字**：從 10 個家族、60 個字裡選 1–3 個（最近用過的字會排在最上面），再選強度 0–10。
3. **怎麼陪它**：選一種方式，每種方式都有一段很短的互動。順序會跟著強度變，並且只標一個「這種時候常用」。
4. **現在呢**：再量一次強度。

每一份心情一開始都是一隻**幼生**。你怎麼陪它，就決定它長成哪一種生物：

| 怎麼陪 | 心理學依據 | 長成 |
|---|---|---|
| 讓它待著 | 接納、觀浪（urge surfing） | 海月水母 |
| 先著陸 | 著陸技巧（看見 5、聽見 4、摸到 3……） | 海馬（尾巴捲住一根海草） |
| 換個殼看看 | 認知重評、拉開距離 | 寄居蟹（每個角度是一種殼） |
| 聽聽它要什麼 | 情緒背後的需要 | 燈籠魚（同一種需要的游成一群） |
| 對自己溫柔 | 自我慈悲的三個部分 | 小丑魚住進海葵 |
| 一件小事 | 行為活化 | 海龜（做到了就出發旅行） |
| 先倒出來就好 | 宣洩 | 被水母吃掉，散成藍眼淚 |
| 細細品嚐、謝謝誰 | 品味、感恩 | 珊瑚 |
| 留給以後 | 正向記憶的保存 | 海面上的瓶中信 |
| 還不想決定 | 允許還沒準備好 | 幼生繼續漂著，一週後自己化成藍眼淚 |

生物之間彼此有關：

- 藍眼淚是水母和珊瑚的食物，水母游過會亮，也會吃飽一點。
- 珊瑚礁長大了，雀鯛會搬進來；手指靠近，雀鯛就躲進珊瑚裡。
- 小事做到了，海龜會出發旅行，帶一個殼回來。大的寄居蟹搬進新殼，舊殼一路讓給小一號的（真實的「空缺鏈」）。
- 同一種感覺每來一次，珍珠貝就多一層，那一層的顏色是你那次選的陪法。七層以上、而且用過三種陪法，才會結成一顆珍珠；只用同一種方式的話，最多留十二層。珍珠記錄的是你陪它走過的路，不是它來了幾次。
- 一個月內用過四種以上的陪法，章魚才會出現（情緒調節的彈性）。
- 很難受的時候，海可能會把你以前寫給自己的一句話，裝在瓶子裡送回來。

「潮汐圖」會把你的紀錄攤開：感覺落在情緒環狀模型的哪裡、對**你自己**來說哪一種陪法讓浪變小（同一種用過三次以上才畫，並標出幾次真的變小；可以分開看「強的時候」和「不那麼強」，因為浪很大時，下一次量本來就容易低一點）、哪一種需要一直出現、你寫給自己的話。這裡不下結論，只把你的資料擺在你面前。

每週一次，海會寄來「這一週的海」：只用你自己的字組成，有你取過的名字、用過的陪法、浪退最多的一次、做到的小事、寫給自己的話。

### 依心理學做的安排

- **強度決定順序，不決定能不能選**：強度 8 以上時，「先著陸、讓它待著、先倒出來」排在前面，「換個殼看看」排最後並註明「浪小一點的時候再換殼也可以」（強度高時認知重評比較難做到）。強度 4 以下則反過來。
- **只標一個「這種時候常用」**：依家族（自責→對自己溫柔、疲憊／難過／孤單→一件小事、生氣→聽聽它要什麼、不安→先著陸或換個殼）、強度，以及同一種感覺最近兩週是不是一直來。
- **宣洩的保護**：同一種感覺最近三次都只「倒出來」，會輕輕提一句也可以換一種試試，不擋。
- **不在難過的時候打擾**：陪完一份心情之後，成就和新發現的通知會安靜約一分鐘再出現；儀式進行中，其他視窗（例如孵化）會等儀式結束。
- 文字裡出現傷害自己的念頭時，會先停下來，提供安心專線 1925、生命線 1995、張老師 1980，以及保護專線 113。

## 光：稀有，而且只獎勵「記下來」

- 水母會慢慢發光（三隻大約每小時 75 光），離開時最多補 6 小時、打 15% 的折。
- **每天前三份心情各 30 光**。不管是什麼感覺、選了哪一種陪法、還是還沒決定，都一樣；結果卡上只用一行小字寫「謝謝你記下它」。
- 陪法、生物、潮汐圖永遠不用光換。和特定陪法有關的成就（五種陪法、章魚、珍珠、第一次倒出來）只留紀念、不給光。
- 心情變成的水母不佔水族箱名額，也不替你賺光。
- 可以刷的地方都收起來了：寶箱 4 小時一次、海螺不給光、漂流瓶裝飾一天一次、呼吸一天三次、剛撈的水母放回大海不給光。

## 棲地

商店的「棲地」不會變出生物，只改變心情長出來的生物待在哪裡：

| 棲地 | 誰會過來 |
|---|---|
| 海草床 | 海馬聚在同一片海草裡 |
| 礁石洞 | 寄居蟹被點到時躲進去；白天燈籠魚待在洞的陰影裡 |
| 月光石 | 晚上燈籠魚繞著它游 |
| 一個空殼（一天一個） | 最大的寄居蟹搬進去，舊殼一路讓給小一號的 |
| 珍珠盒（要先有珍珠） | 擺著你的珍珠 |

## 回來的時候

離開一陣子再回來，所有事情合成一張「歡迎回來」：離開時水母發了多少光、誰出生了、到期的小事（直接在卡上回答）、拆今天的信、這一週的回顧、以及「我現在有感覺」。今天還沒記過心情的話，下方的「心情」按鈕會亮一個很淡的小點。

## 可以做的事

| 動作 | 怎麼做 | 會發生什麼 |
|---|---|---|
| 餵食 | 點水面；按住拖曳可以撒一整排 | 水面也是一把琴：越右邊，音越高 |
| 摸摸 | 按住水母輕輕滑動 | 水母會亮起來、冒出愛心，親密度上升 |
| 說明牌 | 點一隻水母或生物 | 牠身上出現一個圈，細線拉到一塊牌子；牌子自己靠上或靠下，不擋住牠。往空的地方拉 → 詳細；往邊緣拉 → 收合、關上；左右滑 → 換一隻（先水母，再依種類，組內依來到的時間） |
| 呼吸 | 下方「呼吸」選節奏（4・2・6、4・7・8、方塊呼吸） | 所有水母跟著你的節奏一起脈動 |
| 繁殖 | 點成年水母 → 拉開詳細 →「找伴侶」 | 海底長出水螅體，大約一分多鐘後孵化成碟狀幼體 |
| 圖鑑 | 13 種顏色、6 種傘形、8 種花紋、7 種特殊體質 | 特殊體質都有隱藏配方，圖鑑裡有提示 |
| 商店 | 用「光」撈野生水母、布置棲地、買零食、裝飾、主題、升級水族箱 | 9 種裝飾（有些可以點）、5 種棲地、6 種主題 |
| 海的來信 | 每天第一次來 | 選今天的心情，收到一封信、一則水母小知識和禮物 |
| 晚安模式 | 更多 → 晚安 | 畫面變暗，音樂在 15／30／60 分鐘內慢慢變小 |
| 拍照 | 更多 → 拍照 | 存下水族箱的樣子 |

隨機事件：海螢群游過、漂流瓶沉下來、流星劃過水面、野生水母來參觀、海底冒泡泡。

## 裡面是怎麼做的

- **沒有任何圖片或音檔。** 畫面全部用 Canvas 2D 即時畫出來，聲音全部用 Web Audio 即時合成。
- **水母**：傘的輪廓是貝茲曲線，脈動時收縮變形；觸手用「跟隨式約束 + 慣性」的簡單物理，會自然拖在後面；口腕是會擺動的荷葉邊緞帶。
- **基因**：色相、飽和度、傘形、大小、觸手數量與長度、口腕、花紋、發光強度、脈動頻率、特殊體質。孩子會混合父母的基因，偶爾突變。
- **音樂**：D 大調五聲音階，所以怎麼點都好聽。每隻水母依照自己的顏色與體型有一個音，脈動時偶爾唱出來，所以每個人的水族箱會唱不同的歌。
- **生命週期**照真實的水母：水螅體 → 橫裂體 → 碟狀幼體 → 水母體。
- **存檔**只放在這台裝置瀏覽器的 localStorage；設定裡可以匯出、匯入存檔碼。
