# 01 紀錄簿

## 一句話

「更多」裡多一頁，依月份列出每一筆心情紀錄，可以篩選、搜尋，點一筆打開那張紀錄卡；生物還在海裡的話，可以直接跳去看牠。

## 為什麼

紀錄永遠不丟之後，半年會有幾百筆；海裡只留每種最近的幾隻，離開海裡的那些現在沒有地方一筆一筆看。使用者選了這個做法（`docs/plans/cloud.md` 第 3 節做法 1）。

## 入口

- `js/ui-sheets.js` `RENDER.more` 的 `items` 加一列，放在「潮汐圖」後面：`['book', 'book', '紀錄簿', '一共 N 筆・這個月 M 筆']`。圖示 `book` 要新增到 `js/ui.js` 的 `ICONS`（24×24 線條，和其他圖示同一種筆觸：一本翻開的本子）。
- 抽屜：`RENDER.book = (body, arg) => '紀錄簿'`，`RENDER.book.back = 'more'`。`arg` 可帶 `{ fam, turn, month }` 預設篩選（給潮汐圖與日曆之後連過來用，這次不用做連結）。

## 畫面（抽屜裡，照 `.sheet` 的現有樣式）

```
[ 全部 ] [ 生氣 ] [ 不安 ] … 10 個家族 chip（顏色用 famChip 的做法）
[ 全部陪法 ▾ ]  下拉：11 種陪法（turnChip 的名字）      [ 只看有寫字的 ]
[ 🔍 搜尋你寫過的字 ]                                   （input.field；不用放大鏡圖示，用 placeholder 就好）

2026 年 9 月・12 筆
  9/26 14:06  「擔心」「緊張」   浪 7 → 5   海馬     ●
  9/25 22:10  「累」            浪 8 → 8   燈籠魚・休息
  9/25 08:31  「開心」          亮 6 → 7   珊瑚枝
  …
2026 年 8 月・31 筆
  …
[ 再看更早的 ]
```

- 每一列（用 `.row.clickable`）：左邊時間（`timeStr`，`font-variant-numeric: tabular-nums`）；中間第一行是選的字（每個字用「」，最多 3 個），第二行是浪（`浪 i0 → i1`；正向家族寫「亮」；`i0 == null` 寫「未量」；沒有陪法時只寫 i0）＋長成了什麼；右邊一個小色點是家族的顏色（`hsl(fam.hue, sat, 65%)`）。還在海裡的，色點旁多一個很小的「●在海裡」字樣，顏色 `var(--sea)`。
- 長成了什麼：`turn → 物種`：`allow` 海月水母、`reframe` 寄居蟹、`need` 燈籠魚（後面加「・需要的名字」）、`kind` 小丑魚、`step` 海龜、`ground` 海馬、`release` 藍眼淚、`savor` 珊瑚枝、`thank` 腦珊瑚、`keep` 瓶中信、沒有 turn 的寫「幼生・還沒決定」。名字用 `MJ.Feelings.SPECIES[id].name`。
- 月份標題：`sub-h` 樣式，`YYYY 年 M 月・N 筆`。最新的在最上面。
- 一次只渲染 60 列，底部「再看更早的」按鈕（`.btn.ghost.wide`）再加 60 列；3,000 筆時捲動不能卡。
- 篩選與搜尋互相疊加；搜尋比對「選的字」「寫的字 text」「原文 raw」（危機紀錄的 text／raw 不參與搜尋）。改變篩選時回到頂端、重算「N 筆」。
- 空狀態（`.empty`）：沒有任何紀錄：「還沒有紀錄。按下面的「心情」，替一份感覺取名字。」；篩選後沒有：「這個條件下沒有紀錄。」
- 篩選狀態存在 `UI.bookFilter`（不存進存檔），關掉抽屜再開會記得。

## 紀錄卡（點一列）

用 `UI.showModal(render, { cls: 'paper' })`，和來信、漂流瓶同一種紙的樣式。內容由上到下：

1. 小字：`timeStr(e.t)`；右邊家族名（`famChip`）。
2. 選的字：大字，每個字用「」。
3. 浪：`浪 7 → 5`（規則同列表）；下面一行 `陪法：先著陸`（`turnChip`）。
4. 長成了什麼：`長成了一隻海馬`；如果還在海裡：按鈕「去看牠」→ 關掉紙、`UI.callout.show(生物)`。找生物的方法：`Game.eco.find(e.id)`（幼生、寄居蟹、燈籠魚、海龜、海馬、瓶中信、小丑魚）；水母用 `Game.jellies.find((j) => j.origin && j.origin.entry === e.id)`；珊瑚用 `Game.eco.reefs` 的 `items.find((it) => it.entry.id === e.id)`，包成 `{ kind: 'coral', item, reef }`。找不到就不顯示按鈕。
5. 你寫的字：`e.text`（用 `.said` 樣式，標籤依陪法：`reframe` 用 `F.LENSES[e.lens].ask`，`kind` 「你對自己說」，`need` 「被照顧到一點點，會是」，`step` 「想做的小事」＋狀態（做到了・時間／還沒／先放下），`keep` 「寫給以後的自己」，其他「那時候」）。
6. 原文：`e.raw`（有勾選保存才有），`.said` 樣式，標籤「倒出來的」。`e.rawTrimmed` 為真時寫一行小字「原文因為存檔太大，已經省略」。
7. **危機紀錄（`e.crisis`）**：只顯示 1–4，不顯示 5、6，不顯示任何原文；底下一行 `res-care` 樣式的專線連結（和結果卡一樣）。
8. 按鈕：「關上」。

## 資料

只讀 `Game.state.entries`，不改任何欄位。列表用 `entries.slice().reverse()` 一次算好再篩。

## 不做

- 不做編輯、不做刪除單筆（刪除是「重新開始」的事）。
- 不做統計、不做連續天數、不做「你這個月記了比上個月多」這類比較。
- 不做分享。

## 驗收

1. 塞 200 筆（10 個家族、11 種陪法、有些有 text／raw、3 筆 crisis），開「更多 → 紀錄簿」：月份分組正確、每列的字／浪／物種正確、危機列的第二行沒有原文。
2. 篩「不安」只剩不安；選「先著陸」只剩海馬；搜尋一個只在 raw 出現的詞找得到；搜尋只在 crisis 的 raw 出現的詞找不到。
3. 3,000 筆：打開抽屜 < 300 ms（`performance.now()` 量 `openSheet`），第一次只有 60 列，按「再看更早的」增加。
4. 點一列打開紀錄卡；還在海裡的那筆有「去看牠」，按了說明牌指著對的生物（`MJ.UI.callout.thing.entry.id === e.id`）；不在海裡的沒有按鈕。
5. 危機紀錄的卡沒有 text、raw，有專線連結。
6. 手機 390×844：chip 那排可以橫向捲動不換行，列表不擠。
7. 00 的全部測試照樣通過；`docs/features/record-book.md` 新增並標「已有」。
