**金流與 App**（規劃書 `money.md`）
- 用**綠界**，走小額付款；**不做訂閱**；**不做 iOS**（網頁為主，之後最多 Android TWA）。

- 綠界收台幣，主要對台灣；海外使用者的付款以後再用第二條通道（代理商），憑證格式相同。

**帳號與雲端備份**（規劃書 `cloud.md`）
- 要有統一的登入帳號，把心情紀錄備份到雲端：**心情紀錄遺失是重大事故**，比什麼都優先。
- 登入用市面上的帳號授權（Google、Apple 之類），不自己寄 email、不自己管密碼。
- 破解只影響自己、傷害不大：用最低成本的防護（資料只能自己讀寫、限制大小與頻率），不花力氣防作弊。

**多語言**（規劃書 `i18n.md`）
- 先規劃架構，不翻譯。

**同日稍後拍板**
- 大量紀錄：先做**紀錄簿**（`../specs/01-record-book.md`）。
- 心情原文：**A，全部上傳**（不做端對端加密；隱私政策寫清楚不看、不分析、可刪）。
- **Firebase**；匿名帳號自動備份，之後綁 Google。
- 舊網址（Artifact）的資料要能一兩步搬到新網址，而且搬家的機制要做成之後推廣與公告也能用的「館方公告」（`../specs/03-notices-and-move.md`）。
- 正式網站改放 GitHub Pages（Artifact 擋網路，連不到 Firebase）。
- 以上**不在雲端 session 開發**：規格在 `../specs/`，由本機的 session 實作。
