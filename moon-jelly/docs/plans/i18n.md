# 多語言：架構規劃（先不翻譯）

**三行結論**
- 程式裡約 1,500 個中文字串，其中一半是「內容」（感覺的字、陪法、來信、物種說明、名字），另一半是介面。內容不能逐字翻，要由懂心理與那個文化的人重選。
- 架構：介面字串走一個 `T()`，內容做成每個語言一包；地區（不是語言）決定專線；字型與斷行跟著語言換。
- 現在不動程式；等決定第一個外語時，用腳本一次抽出字串（1–2 天），再交翻譯（每個語言約 1–2 週）。

## 1. 現況

| 檔案 | 中文字串數 | 性質 |
|---|---|---|
| `feelings.js` | ~300 | 內容：10 個家族 60 個字、11 種陪法、需要、角度、問題、專線 |
| `content.js` | ~190 | 內容：來信、小知識、療癒句子、名字 |
| `genes.js` | ~80 | 內容：顏色、傘形、花紋、體質的名字與圖鑑提示 |
| `game.js`、`ui*.js`、`ritual.js`、`tides.js`、`callout.js` | ~800 | 介面與通知 |
| `index.html` | ~30 | 介面、aria-label |
| 畫在 canvas 上的字（`drawLabel`） | 少 | 字型要跟語言走 |

## 2. 架構

1. **介面字串**：`MJ.T('feed.title')`、`MJ.T('plate.born', { name })`。字典 `js/lang/zh-TW.js` 是基準，其他語言缺的鍵回退到 zh-TW。鍵用「畫面.意思」命名，不用中文當鍵。
2. **內容包**：`js/lang/<locale>/content.js`，放 feelings、content、genes 的文字部分；程式只留 id 與數值（hue、sat、v、a）。每個語言的 60 個字要重選（例如日文的「悔しい」沒有一對一的中文），來信要重寫，不是翻。
3. **地區與安全**：專線依**地區**不是語言（美國英文與英國英文不同）。`locale = 語言-地區`；地區不明時顯示國際的專線目錄並要求使用者選地區。危機字詞表（自傷）每個語言各一份，要由專業者審。
4. **字型**：zh-TW 霞鶩文楷；ja 用手寫感的日文字型（例如 Klee One）；en 用手寫感的拉丁字型；都要有系統字回退。`MJ.FONT`（canvas 用）跟著換。字型依語言按需載入，不一次載全部。
5. **版面**：不假設標籤只有兩個字（底部選單、餵食、心情）；英文會長一倍，用 `min-width` 與省略；日期時間用 `Intl.DateTimeFormat`；數字用 `Intl.NumberFormat`（光的數字已用 `U.fmt`，改成依 locale）。不用做由右到左。
6. **選語言**：`navigator.language` 自動，設定裡可以改，存進存檔。
7. **打包**：單檔版預設只含 zh-TW，其他語言的字典與內容包按需 fetch（或做成每個語言一個單檔）。
8. **Artifact／預覽**：Google Fonts 只允許 fonts.googleapis.com，日文與拉丁字型都在，可以。

## 3. 做法與工時

| 步驟 | 內容 | 估計 |
|---|---|---|
| 抽出字串 | 腳本掃描所有 `'…中文…'`，產生鍵與 `zh-TW.js`，把程式改成 `T()`；人工檢查 | 1–2 天 |
| 拆內容包 | feelings、content、genes 拆成 id＋文字 | 1 天 |
| 地區與專線 | locale 機制、專線目錄、地區選擇 | 1 天 |
| 字型與版面 | 依語言換字型、檢查長字串的版面 | 1 天 |
| 每個語言 | 介面翻譯（約 15,000 字）2–3 天；內容重寫 3–5 天（要懂心理的人）；專線與危機字詞審核 1 天；測試截圖 1 天 | 1–2 週 |
