# 日夜

## 一句話

海讀裝置的時間：白天有從上面來的光，夜裡把太陽關掉，海雪會閃、水母下沉放慢、聲音變少。用「有／沒有」的差別，不是把顏色調深。

## 已有（方案 A，2026-09-26）

**時鐘**：`js/daynight.js` 是唯一的時鐘，其他程式只讀 `MJ.Day.sun`（太陽 0..1）、`MJ.Day.night`（= 1 − sun）、`MJ.Day.phase`。

| 時段 | 時間 | sun |
|---|---|---|
| 白天 | 07:00–17:30 | 1 |
| 傍晚 | 17:30–21:00 | 1 → 0（平滑） |
| 夜 | 21:00–05:30 | 0 |
| 黎明 | 05:30–07:00 | 0 → 1 |

- 每 15 秒重新看一次系統時間；回到前景（`visibilitychange`）立刻看。自然變化用約 20 秒慢慢過去。
- 撥時鐘：`MJ.Day.setClock(22)`（小時，可小數；`null` 恢復），或網址加 `?clock=22`，都立刻套用。手機上不用改系統時間就能看夜晚。

**夜裡會發生的事**（都乘 `night`，所以傍晚是連續的）

| 東西 | 白天 | 夜 | 在哪裡 |
|---|---|---|---|
| 光束 | `rayA × 1.25` | 0，整個不畫 | `world.js` `drawBack` |
| 沙地的焦散光斑 | 原值 | 0，不畫 | 同上 |
| 水面的光 | alpha .13、波紋線 .12 | .02、.03 | 同上 |
| 背景頂端 | 主題的 `grad[0]` | 往 `grad[1]` 靠 60%，第二段往第三段靠 25%，最深處不變 | `world.js` `renderBg(night)`，另外預畫一張 `bgNight`，每幀依 `night` 混合 |
| 海雪 | 全部、原速 | 四成淡掉（×0.6）、下落速度 ×0.7 | `world.js` `buildSnow`、`update`、`drawBack` |
| 夜光藻（14% 的海雪） | 不閃（無光深淵主題例外，照舊） | 每粒每 20–40 秒亮一下，峰值 alpha .5、hue 195、半徑 6–10 px | 同上 |
| 水母的目標高度 | 上緣 H×0.10 | 上緣往下到 H×0.23，整群往下沉 | `jelly.js` `pickWanderTarget` |
| 水母脈動 | ×1 | ×0.85 | `jelly.js` `update` |
| 水母唱歌機率 | ×1 | ×0.5 | `jelly.js` `onPulse` |
| 水母光暈 | ×1 | ×0.9（光束關掉後靠對比反而更像一盞燈） | `jelly.js` `draw` |
| 鈴聲 | 密度 ×1、音域 5–14 | 密度 ×0.4、音域 3–11 | `audio.js` `tick` |
| 和弦墊 | ×1 | ×0.85 | `audio.js` `applySettings` |
| 水聲 | ×1 | ×0.7 | 同上 |
| 燈籠魚 | 白天躲礁石洞的陰影 | `sun < 0.5` 就算晚上，游上來 | `creatures.js` `Eco.update` |

**沒有變的**：每小時的光量、HUD 的「+N／小時」、給光的事件（流星、海螢、漂流瓶、寶箱）。夜裡新增的亮點（海雪閃）不給光、不能點。

**量過**：夜裡畫面上半段比白天暗 22%（手機）、25%（電腦），舊的重新設計版只有 9%。

**測試**：`scratchpad/v2/dn.js`（換 session 要重寫）：亮度、傍晚介於中間、光速率不變、水母目標更低、`?clock=22`、20 秒過渡。

依建議的順序：

1. 傍晚的光變暖、變斜（點子 2）：17:30 起光束色彩往 `[236,204,176]` 偏最多 40%，只在 18:30–19:30；傾斜 +0.12。
2. 有人留了一盞燈（5）：沙地左側一小圈暖光 `rgba(235,222,196,.05)`，半徑 W×0.25，只在夜裡。
3. 水面的月光路（6）：夜裡幾段碎的短橫線在晃，位置每天不同，不畫月亮；有月亮的主題不重複畫。
4. 生物各有夜裡的樣子（8）：海葵收攏、小丑魚窩進去、海馬只擺不移動、寄居蟹反而出來走。
5. 訪客只在開館時間來（9）：野生水母訪客 07–18 才出現；給光的事件不分時段。
6. 夜裡碰水會亮一下（10）：點水面多冒 3–5 粒藍白小火花，不給光。
7. 館的營業時間感（11）：標題下一行小字「夜間開放中」；不寫評價，不用圖示。
8. 心情儀式的夜間背景（12）：夜裡儀式後面的海暗到 .45（白天 .35），卡片後一圈檯燈光。
9. 天亮的過程（13）：隨 1 與現有的過渡自然發生，不通知。
10. 六個主題各有夜版（14）：櫻花夜裡花瓣少、極光更慢更淡、滿月的月光路強一點但總光不增。
11. 海龜天亮再出發（15）：改變玩法節奏，結果卡要明說，放最後。

## 決定過的事

- 2026-09-26：使用者把手機時間調成白天與晚上，看不出重新設計版的差別。三人小組（美術指導、色彩心理、互動與生態）診斷是「全部在把很淡的圖層再調淡」，建議用有／沒有的差別。使用者選方案 A。
- 夜靠減法和一個小暖光：不畫大月亮、不撒星星、不用紫色漸層、不加黑幕；最深處不更黑。
- 夜晚不會自動進入晚安模式；晚安是使用者自己選的、更暗（.62）。
- 燈籠魚原本自己看時鐘（18–06），改成從 `MJ.Day` 拿，全站只有一個時段定義。
