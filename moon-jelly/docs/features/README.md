# 功能一覽

每個功能一個檔案，讓人（和 Claude）不用讀程式就知道現在有什麼、還沒有什麼。

每個檔案固定四段：**一句話**、**已有**（現在的行為與參數）、**待開發**（想做但還沒做的，含專家建議）、**決定過的事**（為什麼這樣做、什麼不做）。
改一個功能之前先讀它的檔案，做完更新它；專家報告的全文放 `../panel/`，規劃書放 `../plans/`，這裡只留結論。

| 功能 | 狀態 | 一句話 | 檔案 |
|---|---|---|---|
| 日夜 | 已有方案 A；方案 B 待開發 | 讀裝置時間，夜裡把太陽關掉、海雪會閃、水母下沉放慢、聲音變少 | [daynight.md](daynight.md) |
| 生物說明牌 | 已有 | 點一隻水母或生物，圈和細線指著牠，牌子可以拉開、關上、左右滑換一隻 | [callout.md](callout.md) |
| 心情儀式 | 已有 | 倒出來、取名字、怎麼陪、現在大概在哪裡；每份心情長成一種生物 | `../../README.md`「心情」一節、`js/ritual.js` |
| 光的經濟 | 已有 | 光很稀有：每天前三份心情各 30，不因陪法不同；能刷的地方都收起來 | `../../README.md`「光」一節、`js/game.js` |
