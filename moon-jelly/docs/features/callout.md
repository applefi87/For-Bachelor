# 生物說明牌

## 一句話

點一隻水母或心情長出來的生物，牠身上出現一個圈，一條細線拉到一塊牌子；牌子用原本的樣式（霧面玻璃、圓角、手寫字），自己閃開生物。

## 已有（2026-09-26）

程式：`js/callout.js`（位置、拖拉、左右滑、排隊）、`js/ui-eco.js` `UI.creatureParts`（每種生物牌上寫什麼）、`css/callout.css`。取代了原本的水母名片抽屜和畫在海上的虛線圈。

- **位置**：牌子停在和生物相反的那一半：生物在上半，牌子貼著底部選單；在下半，牌子在頂部資訊列下面。生物游到牌子底下、跑到另一半、（電腦）橫向離太遠，牌子才淡出淡入換位置，不追著跑。牌子靠上時，通知改從下面出來。
- **圈與線**：圈的大小跟各生物的點擊範圍一致（`anchorOf`）；線從圈上最靠近牌子的點拉到牌子邊緣，每一幀跟著生物。生物游出畫面或躲進洞裡，線先淡掉、牌子留著。
- **往空的地方拉**（靠下的牌子往上、靠上的往下）＝**詳細**：上面的內容不換，下面多出來（水母：親密度以外的數據、找伴侶、改名、回到大海；生物：引用的字、物種說明）。詳細時牌子最多長到生物旁邊，除非那邊剩不到 280px。
- **往邊緣拉**：詳細時先收合；再拉一次滑出去關上。詳細內容比牌子長時，上下滑是捲動，要收合從上面那一條拉。
- **左右滑**（或箭頭、鍵盤左右）＝換一隻：先水母（住客再訪客，依來到的時間），再依種類分組（幼生、寄居蟹、燈籠魚、小丑魚、海葵、海龜、海馬、珊瑚、瓶中信、珍珠貝、章魚），組內依誕生時間；最後一隻接回第一隻。牌子上方小字寫「水母 2 / 3」。
- **關上**：點水、開儀式、開抽屜、開餵食選單、任何模式、Esc、右上的 ×。生物離開水族箱也會關。
- **通知之後自己出現**（排隊，等你手上沒在看別的）：陪完心情的結果卡關上後（「剛長出來」；被水母吃掉的「倒出來」指那隻水母）、出生（「剛出生」）、撈到（「剛撈到」）、長大、章魚出現、珍珠結成（珍珠卡之後）、海龜出發與回來、離開時出生的水母（最多兩隻，歡迎回來卡之後）。排隊超過兩分鐘、生物不在了就不出。
- **危機**：寫過自傷字詞的那一份，結果卡之後不自己跳牌子；整段安靜期內排隊清空。
- **水族箱的小事件**（漂流瓶、海螢、訪客、泡泡）**維持只有上方一行字，沒有牌子也沒有線**：這些要自己去找。

**測試**（暫存區 `scratchpad/v2/co1–co6.js`）：桌面與手機、真實觸控手勢、19 種生物逐一打開並滑到底、通知之後的牌子、小事件不出牌子。

## 決定過的事

- 使用者要的是重新設計版「細線指著生物、不擋畫面」的精神，牌子本身的樣式照舊版。
- 第 18 項（水族箱小事件）明確不要細線。
- 「詳細」不換內容、只多顯示，所以一定要看的（字、時間、浪、要按的按鈕）放上面。
